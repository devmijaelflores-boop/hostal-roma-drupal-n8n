# Ejemplos académicos SUNAT beta

**SIN VALIDEZ TRIBUTARIA. Identidades genéricas y certificado académico autofirmado.** No representan ventas, cobros ni datos fiscales del hotel o sus huéspedes.

- [XML de factura F901-1](factura-F901-1.xml) y [CDR recibido en beta](factura-F901-1-cdr.zip).
- [XML de boleta B901-1](boleta-B901-1.xml) y [CDR recibido en beta](boleta-B901-1-cdr.zip).
- [Representación PDF de factura](factura-representacion-beta.pdf).
- [Representación PDF de boleta](boleta-representacion-beta.pdf).

Ambos CDR contienen código 0 del entorno beta. Las representaciones PDF se imprimieron desde la aplicación y mantienen su aviso académico. Los XML contienen certificados públicos; **no se incluye la clave privada ni credenciales**. Los archivos ZIP recibidos contienen un directorio vacío `dummy/` y su XML de respuesta; no es necesario extraerlos para ver las representaciones PDF.

Ver [evidencia del servicio](../verificacion-sunat-beta-real.json) y [guía de la fase](../sunat-beta.md). SUNAT aclara que [beta prueba estructuras y no verifica la consistencia de los datos](https://cpe.sunat.gob.pe/noticias/servicio-beta-para-realizar-pruebas-ubl-21).
